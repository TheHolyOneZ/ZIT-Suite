Why ZIT-Suite

GitHub's website handles one repo at a time. You have dozens.

Archiving dead projects, finding every failing workflow, rotating a secret everywhere, adding missing licenses, cleaning up merged branches, answering issues spread over a dozen repos — ZIT-Suite turns afternoons of clicking into a few checked boxes.

Bulk everything

Archive, delete, change visibility, rename, transfer, label, protect branches, add topics or set secrets on many repositories at once — always through a queue with a real dry run.

Cross-repo views

One inbox for issues, one for pull requests, one CI board, one release board, one security overview — across every repository you own.

Git without the terminal

Home turns any folder into a project: save versions, upload, get latest, branches, diffs, park changes and undo — with libgit2 built in.

Safe by design

Your token lives in the OS keychain, destructive actions need typed confirmation and a grace countdown, pushes are never forced, secrets are sealed on-device.

Insight, not noise

Health scores, tidy checks with one-click fixes, custom rules, traffic history beyond GitHub's 14 days, contributor stats and a full code audit.

A real workbench

A distinctive blueprint design in light and dark, accent colors, a command palette, keyboard-first navigation, English and German.

Features

Everything you do on GitHub — for all your repositories at once.

Organized in three pillars, BUILD, MANAGE and SHIP. Every tab is a self-contained module, and everything bulk or destructive goes through the queue.

BUILD

Write, organize and keep code in sync.

B-01

Home — Git for people who don't want to learn Git

  • Workspaces: any folder becomes a project card with a one-line status — unsaved, not uploaded, new on GitHub, all good
  • One-click setup: git init, a suggested .gitignore, a new private GitHub repo, first version and upload
  • Save versions (commit) and Save & upload (push), discard per file, secret-file warnings with "Don't share"
  • Per-file diff, undo last save while it's only local, park my changes (stash) and bring them back
  • Get latest (fast-forward or clean merge) with a conflict helper — mine or theirs per file
  • Push target + reference repo: compare your fork with the original and bring upstream changes in
  • Automation: save every N minutes or after N quiet minutes, optional auto-upload, message templates, runs from the tray
  • Files & sharing: tick what goes to GitHub, "usually not shared" suggestions, raw .gitignore editor
  • Branches, history with "uploaded" marks, clone any repo, open in VS Code or your terminal, start a pull request from a branch
B-02

Files & Editor

  • Browse and edit any repository on GitHub with a CodeMirror 6 editor, syntax highlighting, tabs and search
  • Add, rename, move and delete files — saved as one atomic commit or to a new branch + PR
  • Upload files and whole folders (respects .gitignore), image and Markdown preview
  • File history, revert, blame view, executable bit kept, never overwrites a moved branch
B-03

Branches

  • Every branch with last commit, open PR, protection and ahead / behind
  • Find stale and merged branches, clean up in one go, real rename, set default
  • Branch protection with status checks and a rulesets editor
  • Create a branch or protect the default branch on many repos at once
B-04

Dependencies — a dependency scanner for every repo

  • Reads package.json, Cargo.toml, requirements.txt, pyproject.toml, go.mod, pom.xml — anywhere in a monorepo
  • Detects the real tool: pnpm, yarn, bun, npm, deno, pip, poetry, uv, pdm, cargo, go, maven, gradle
  • Latest versions from npm, crates.io, PyPI, the Go proxy and Maven Central · outdated and version conflicts
  • Bump a version across repos — one PR or commit per repository, formatting kept

MANAGE

Keep hundreds of repositories in order.

M-01

Repositories — the repository manager

  • All repositories with full pagination and an ETag cache — re-syncs cost almost nothing against the rate limit
  • Health score and lifecycle (active, dormant, dead, empty, archived), filters, saved views, local tags, table + grid
  • Bulk: archive / unarchive, private / public, delete, description, topics, clone to this computer
  • Cleanup presets, create repository (README, .gitignore, license, template), exports
M-02

Issues

  • A cross-repo issue inbox with a query builder and saved views
  • Timeline events, reactions, sub-issues, pin, transfer, lock
  • Issue templates and issue forms in the create dialog
  • Bulk triage, labels sync across repos, milestones, CSV / JSON export
M-03

Pull Requests

  • Cross-repo PR inbox with CI, review decision and mergeability
  • Diff viewer with inline review comments and multi-line ranges
  • Suggested changes with one-click Apply, batch reviews
  • Merge, squash, rebase, auto-merge, update branch — in bulk
M-04

Collaborators

  • Access scan: People, Repositories and a Matrix view
  • Invite, change roles, revoke everywhere, copy access, compare & align
M-05

Webhooks

  • Hooks grouped by endpoint across all repos with delivery health
  • Deliveries, redeliver, test push, HMAC signature verifier, bulk edits
M-06

Secrets & Variables

  • GitHub Actions secrets, variables and environments grouped by name, with rotation age and drift
  • Set or rotate a secret on many repos — sealed on your device, never written to disk
  • Usage finder: which workflows use a secret
M-07

Security

  • Dependabot, code scanning and secret scanning alerts across all repos
  • Fix plan: one upgrade per package that clears all its alerts
  • Posture grid with grades, apply a baseline, Dependabot config generator
M-08

Inbox

  • GitHub notifications grouped by why, with open / merged / closed state
  • Bulk read / done / mute, saved views, desktop alerts, watching manager
M-09

Gists · Stars · Search

  • Gists with revisions and comments · Stars with star lists and awesome-list export
  • Search code, repos, issues, commits and people — code grouped per repo, saved searches
M-10

Insights

  • Overview KPIs, tidy checks with bulk fixes, custom rules
  • Traffic with a local history beyond 14 days, contributor stats
M-11

Code Audit — what is a repo made of?

  • Lines of code, files, size, commits, lines added and removed over the whole history, people
  • Language breakdown, monthly activity and a tree-style file tree with sizes and lines (export .txt / .json)
  • Most changed files, compare with an earlier audit, audit a local folder straight from disk

SHIP

Build, release and automate.

S-01

Actions

  • Cross-repo CI board: failing first, success rate, live runs
  • Jobs, steps and logs opened at the first error · re-run, cancel, artifacts
  • Run workflow_dispatch with a form · workflow editor with templates

S-02

Releases

Scheduler

Safety first

Built so one wrong click can't hurt 200 repositories.

Bulk tools are only useful if you can trust them. ZIT-Suite shows you exactly what will happen before anything happens.

Token in your OS keychain

Windows Credential Manager, Secret Service or KWallet. Never in a file, never exposed to the interface.

Real dry run

Every repository is checked first: ready, no change or blocked — and why.

Queue with a grace period

Actions wait in a persistent queue with a countdown. Pause, cancel or skip any time — even after a restart.

Typed confirmation

Deleting or transferring repositories requires typing the confirmation out.

No force pushes

Home never force-pushes. Conflicts abort untouched unless you choose a side.

Secrets sealed on-device

Actions secrets are encrypted locally with each repository's public key and never written to disk.

No telemetry

ZIT-Suite talks to GitHub and nothing else. No analytics, no account, no tracking.

Under the hood

Native, fast and light.

A Rust core with a React interface, packaged with Tauri — a small, native app instead of a bundled browser.

Tauri 2 · Rust

GitHub REST + GraphQL client with pagination, ETag cache and rate-limit tracking, libgit2, OS keychain.

React 19 · TypeScript

Strict TypeScript, TanStack Query, CodeMirror 6, Tailwind CSS 4 — typed bindings generated from Rust.

Modular

Every tab is a self-registering module. Palette, shortcuts and settings are derived from the registry.

Tested

FAQ

Questions, answered.

Is ZIT-Suite free?

Yes — free and open source under the GNU General Public License v3.0. No account, no subscription, no ads.

Where can I download ZIT-Suite? Is it on GitHub Releases?

Precompiled installers (.exe, .deb, .rpm) are published only on this website, zsync.eu/zit-suite. The GitHub repository has the source code only — no prebuilt files. You can always build ZIT-Suite yourself from that source; installers from anywhere else are not official.

Do I need Git installed?

No. Git is built in (libgit2): cloning, committing, pushing, pulling, branches, stashes and merges work without a git executable.

Which systems are supported?

Windows 10 and 11 (installer .exe) and 64-bit Linux — .deb for Debian, Ubuntu and Mint, .rpm for Fedora and openSUSE. macOS builds are possible from source but not officially tested yet.

Where is my GitHub token stored?

In your operating system's keychain (Windows Credential Manager, Secret Service or KWallet on Linux). It stays in the Rust backend and is never written to a file.

Can it accidentally delete my repositories?

Every destructive action goes through the queue: a dry run shows what happens per repository, deletes and transfers need typed confirmation, and a grace countdown lets you cancel.

How does it deal with GitHub's rate limit?

Lists are cached with ETags (unchanged answers don't count), GraphQL replaces hundreds of requests where possible, and your remaining budget is always visible in the status bar.

Does it work with organizations?

Yes. Switch between your account and your organizations; repositories, issues, pull requests and more follow the selected scope.

Which languages does the interface support?

English and German, switchable with one click. Languages are plain JSON files, so adding more is easy.

How is this related to ZRepoManager?

ZIT-Suite is the ground-up rebuild of ZRepoManager: every old feature is back, stubbed features now really work, and it adds Home, Insights, Security, Actions, Releases, Search, Inbox, Code Audit and more.
